# AE6106-sg-condo-briefing
R Markdown code that reproduces every table and figure in our investor briefing on Singapore's private condominium market, using URA transactions (Sep 2021–Aug 2026, 121,563 units). Covers price and volume trends, CCR/RCR/OCR comparisons, property types, new sale vs resale, and floor levels. NTU AE6106 group assignment.
